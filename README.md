# Lineflow · 动线工作室

给已有流程图、架构图或思维导图加上流动箭头、光点和虚线，导出无限循环 GIF。

## 使用

1. 点「导入你的流程图」，选 PNG、JPG、WebP 或 SVG；也可以拖入图片。
2. 沿已有连线依次点选起点、拐点和终点，按 Enter 完成；双击也可结束。
3. 选择路径，拖动控制点贴合底图。设置折线 / 曲线、颜色、粗细、样式和方向。
4. 调整全局速度、粒子间距和发光，选择导出宽度、时长与帧率。
5. 点「导出 GIF」，等待完成后点「下载 GIF」。

这是手动描线工具，不会自动识别图片里的连接线。图片中的原始线条和箭头保留为静态底图；导入没有箭头的原始图通常效果最好。SVG 会栅格化为底图，不会导入其可编辑路径。GIF 使用 256 色调色板；渐变和照片可能有轻微色差。透明区域默认使用白色背景。

## 工程和快捷键

- 工程会尝试自动保存在当前浏览器。较大图片可能超过浏览器存储空间，此时请使用「保存工程」。
- 「保存工程」下载包含图片和路径的 `.lineflow.json` 文件；「打开工程」可继续编辑。
- P：开始画路径；V：选择；Enter / 双击：完成；Esc：取消。
- 画路径时 Backspace：撤回最后一个点。
- Delete / Backspace：删除选中路径。
- ⌘Z / Ctrl+Z：撤销；⌘⇧Z / Ctrl+Shift+Z：重做。
- 空格：播放 / 暂停。
- 图片最多 20 MB，过大图片自动缩小到 6000 px 边长和 2400 万像素以内；最多 300 条路径，每条 1000 个控制点。
- 导出宽度 640 / 960 / 1200 / 1600 px，时长 2 / 3 / 4 / 6 秒，12 / 20 / 25 fps。为控制内存，超长图片的输出会按比例缩小到约 220 万像素、最长 8192 px。

所有图片处理和 GIF 编码都在浏览器中完成；不需要上传图片，也不依赖外部 CDN。推荐在桌面版现代浏览器使用。

## 本地运行

双击 `打开 Lineflow.command`，或在当前目录执行：

```sh
python3 local_server.py
```

需要 Python 3。浏览器会自动打开。保持终端窗口运行；关闭时按 Ctrl+C。不要直接双击 `dist/index.html`，因为浏览器的模块和 Worker 需要 HTTP 地址。

## 验证

```sh
npm run check
node tests/gif-encoder.test.mjs
node tests/gif-worker.test.mjs
```

测试无需 npm 依赖；GIF 像素检查需要 Python Pillow。编码器已验证 16 个 GIF、24 个解码帧、LZW 字典扩展和重置、差异帧、透明度扁平化、时间及循环信息。浏览器实际导出的示例为 960×640、60 帧、3000 ms，确认帧间像素变化和无限循环。
