# Lineflow 标志

两条并行、略微错位的曲线表现连接线正在流动。浅米色与暖橙色形成前后层次；深蓝底色与工具界面一致。图形没有箭头，缩小为浏览器标签图标时仍能识别。

- `../dist/assets/lineflow-mark.svg`：产品图标、页眉和 favicon 的矢量源文件。
- `lineflow-logo.svg`：图标、英文字标与中文名称的横版矢量标志。
- `lineflow-icon-1024.png`：1024 × 1024 透明背景 PNG。
- `lineflow-wordmark-1080.png`：1080 × 256 透明背景 PNG。

配色：深蓝 `#173448`，浅米 `#F7EFE0`，暖橙 `#F47B50`。放大或制作印刷物时推荐使用 SVG。
