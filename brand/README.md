# Lineflow 标志

图形从浅金色圆点出发，沿暖橙色连线转弯，最后成为向右的箭头。圆点代表路径起点，箭头代表流动方向。深蓝色方形承接工具现有的界面配色。

- `../dist/assets/lineflow-mark.svg`：产品图标、网页页眉和 favicon 的矢量源文件。
- `lineflow-logo.svg`：图标 + 英文字标 + 中文名称的横版矢量标志。
- `lineflow-icon-1024.png`：1024 × 1024 透明背景 PNG，可用于头像、应用图标和社交资料。
- `lineflow-wordmark-1080.png`：1080 × 256 透明背景 PNG，可用于横幅和介绍资料。

配色：深蓝 `#173448`，暖橙 `#F47B50`，浅金 `#F5CF95`。缩放时推荐优先使用 SVG。
